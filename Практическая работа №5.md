# Гурова Варвара ИСП211
## МДК04.01 Практическая работа 5. Разработка внедряемого ПО
### Ситуация 1: Электронный журнал группы

### Цели и задачи:

#### Цель 1 : Автоматизировать учет успеваемости студентов
#### Цель 2 : Упростить контроль посещаемости
#### Цель 3 : Ускорить формирование отчетов
#### Цель 4 : Повысить прозрачность для студентов и родителей
#### Цель 5 : Снизить нагрузку на преподавателей

### Задачи: выделить модули системы, описать назначение каждого модуля, показать схему интеграции, определить связи между модулями, составить план проверки совместной работы.

### Модули и их назначение:

#### 1. Модуль авторизации
#### 2. Модуль успеваемости
#### 3. Модуль посещаемости
#### 4. Модуль расписания
#### 5. Модуль уведомлений
#### 6. Модуль отчетов

### Основные модули и их функции:

|№| Модуль | Назначение | Функции |
|---|---|---|---|
|1| Авторизация | Проверка учетных данных | Вход в систему, разграничение прав (преподаватель, студент, админ), выход |
|2| Успеваемость | Хранение и обработка оценок | Выставление оценок, редактирование, просмотр, расчет среднего балла |
|3| Посещаемость | Учет присутствия студентов | Отметка «Н», «Б», «У», сводка по пропускам |
|4| Расписание | Хранение расписания занятий | Просмотр пар на день/неделю, привязка к группе и преподавателю |
|5| Уведомления | Оповещение об изменениях | Уведомления о новых оценках, пропусках, изменениях в расписании |
|6| Отчеты | Формирование статистики | Отчет по успеваемости, отчет по посещаемости, сводная ведомость |

### Схема интеграции модулей:

Пользователь → Интерфейс → Авторизация → [Успеваемость | Посещаемость | Расписание] → База данных → Уведомления → Отчеты

### Связи между модулями:

#### 1. Авторизация → определяет роль пользователя и доступ к модулям
#### 2. Успеваемость → хранит оценки, передает данные в отчеты
#### 3. Посещаемость → отмечает пропуски, передает данные в отчеты
#### 4. Расписание → показывает пары, связано с успеваемостью и посещаемостью
#### 5. Уведомления → получает данные от успеваемости и посещаемости
#### 6. Отчеты → собирает данные от всех модулей

### План проверки работы модулей:

|№| Что проверяем | Ожидаемый результат |
|---|---|---|
|1| Вход в систему под разными ролями | Успешный вход, доступ к нужным модулям |
|2| Выставление оценки студенту | Оценка сохранилась в базе |
|3| Отметка посещаемости | Данные обновились |
|4| Просмотр расписания | Пары отображаются корректно |
|5| Получение уведомления о новой оценке | Уведомление пришло |
|6| Формирование отчета по группе | Данные верны |
